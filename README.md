# L’éclaireuse — première reconstruction GitHub Pages

## Mise en ligne
1. Créer un dépôt GitHub public.
2. Ajouter tous les fichiers de ce dossier à la racine du dépôt.
3. Settings > Pages > Deploy from a branch > main > / (root).
4. Ouvrir l’URL fournie par GitHub Pages.

## Important
- Cette première reconstruction reprend la structure et les textes publics du site Wix consulté le 20 novembre 2026.
- **Ce n’est pas une copie visuelle exacte** : les images originales, les icônes et les dimensions/cadrages précis n’étaient pas récupérables. Les blocs « Photographie Wix à intégrer » sont des emplacements temporaires.
- Les pages de mentions légales, confidentialité et cookies sont des emplacements à compléter avec les textes réels.
- Le formulaire de contact est volontairement non fonctionnel : il n’envoie aucun message.
- Le bouton de réservation mène à la section tarifs ; aucun système de prise de rendez-vous n’est connecté.
- Pour une reproduction fidèle, fournir des captures complètes des huit pages et les fichiers d’images/SVG originaux.
