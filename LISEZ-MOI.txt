L’ÉCLAIREUSE — Pages CMS

1. Sauvegardez votre dépôt GitHub.
2. Déposez TOUS les fichiers de ce dossier à la RACINE du dépôt (y compris pages.yml et le dossier contenu).
3. Dans Pages CMS, rechargez la configuration.
4. Modifiez les champs et enregistrez : GitHub Pages publiera automatiquement.
5. Les images principales restent celles des maquettes tant que le champ image est vide. Pour les remplacer, importez une image via le champ image.
6. Les formulaires ne sont pas reliés à un service de réception et les prix restent fictifs.
7. Pour tester les données JSON en local, servez le dossier via un serveur HTTP ; ouvrir index.html en file:// affiche la version intégrée de secours.
